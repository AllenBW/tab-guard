Checking Firefox…

Welcome to Tab Guard

Tab Guard watches Firefox's tab processes from the menu bar. When one grows past your limits it can close it, and Firefox shows that tab as crashed with a Restore button. New installs start in Watch only, so nothing is closed until you pick another mode above.

The first time you use Which site is which?, macOS asks whether Tab Guard may control Firefox. That's only used to open Firefox's about:processes page.
